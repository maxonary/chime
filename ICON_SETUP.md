# Chime App Icon Setup

The icon is `chime-icon.svg` - a simple evil eye (🧿) on grey background (#999999).

## To set in Xcode:

1. Open `Assets.xcassets`
2. Select `AppIcon`
3. Either:
   - **Option A**: Open the `.svg` file in a tool like Figma or online converter, export as PNG at 1024x1024, and drag into Xcode
   - **Option B**: Use this online tool to convert: https://ezgif.com/gif-to-png
   - **Option C**: Screenshot the preview at different sizes and drag in

The SVG is self-contained and can be opened in any modern browser or design tool.
